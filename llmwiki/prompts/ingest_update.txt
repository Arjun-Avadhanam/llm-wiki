# WORKFLOW

Phase 1 — Read the existing page (if any). Understand its current structure, sections, and existing [[wikilinks]].

Phase 2 — Identify what to add or revise based on the source excerpt and the change description. Be substantive — wiki pages should be rich, not summary-thin.

Phase 3 — Check for contradictions. If the new source contradicts existing content on the page:
  - Do NOT silently overwrite. Instead, ADD a "## Contradictions" section near the bottom that records both claims with their sources.
  - Example:
    ## Contradictions
    - Source A ({{source_a_filename}}) states X. Source B ({{source_b_filename}}) states Y. (Suggest human review.)

Phase 4 — Update frontmatter:
  - Add the new source ({source_filename}) to the `sources` list if not already present
  - Set `updated` to today's date ({today_date})
  - If creating a new page, set `created` to today's date as well
  - Preserve any existing frontmatter fields you don't have a reason to change

Phase 5 — Maintain cross-references. Preserve all existing [[wikilinks]]. Add new [[wikilinks]] for any concepts newly mentioned that already have pages (or should have pages — refer to the wiki's general structure if unsure).

Phase 6 — Output the COMPLETE updated page content (full markdown including frontmatter). Do not output a diff or just the changed sections.

# HARD RULES

1. APPEND, never silently overwrite. When adding new information, integrate it into the appropriate existing section. If the new info contradicts existing claims, use the ## Contradictions section.
2. Preserve every existing [[wikilink]]. You may add new ones; you may not remove existing ones unless the linked content is being removed.
3. Update the `sources` list and `updated` date in frontmatter on every edit. These are non-negotiable.
4. Output the COMPLETE page content, not a diff. The CLI will overwrite the file with whatever you produce.
5. NEVER fabricate information that is not in the provided source excerpt or the existing page. If something is unclear, omit it rather than guess.
6. Stay within the page template's structure. You may add subsections within the defined sections, but do not invent top-level sections that the template doesn't have.
